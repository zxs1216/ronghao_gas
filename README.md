# 荣浩燃气 Home Assistant 集成

这是我为 Home Assistant 写的荣浩燃气自定义集成，用来读取荣浩能源燃气云平台中的账户、燃气表和用气记录。这个项目不是荣浩能源官方项目，接口或平台规则变化后，集成可能需要跟着调整。

## 我做了什么

安装以后，我可以在 Home Assistant 里看到这些数据：

- 账户余额和气量余额
- 燃气表当前读数和累计用气量
- 最近一次购气金额
- 最近一次用气量、用气金额和用气时间
- 最近 30 天用气统计
- 最近 12 个月用气统计
- 最近一次从平台刷新数据的时间
- `ronghao_gas.refresh` 手动刷新服务

数据来自荣浩燃气云平台，默认按配置的时间间隔自动刷新。我目前提供 6、8、10、12 和 24 小时几种轮询间隔，默认值为 12 小时。若平台对请求频率、登录状态或接口参数做了限制，Home Assistant 里的数据可能会暂时变成不可用。

## 通过 HACS 安装

这个仓库已经按 HACS 的集成结构整理。若仓库已经进入 HACS 默认市场，可以直接搜索“荣浩燃气”安装；如果还没有进入默认市场，可以先在 HACS 中添加这个自定义仓库：

1. 打开 HACS，进入“集成”。
2. 点击右上角菜单，选择“自定义仓库”。
3. 填写 `https://github.com/zxs1216/ronghao_gas`。
4. 类型选择“集成”，保存后搜索并安装“荣浩燃气”。
5. 安装完成后重启 Home Assistant。

以后我发布新的 GitHub 版本和标签，HACS 就可以识别更新并提示升级。升级前建议先确认当前集成能够正常读取数据；如果升级后出现问题，可以在 HACS 中回退到之前的版本。

## 手动安装

把仓库中的 `custom_components/ronghao_gas` 整个目录复制到 Home Assistant 配置目录的 `custom_components/` 下，最终目录结构应为：

```text
config/
└── custom_components/
    └── ronghao_gas/
        ├── __init__.py
        ├── api.py
        ├── config_flow.py
        ├── const.py
        ├── coordinator.py
        ├── manifest.json
        ├── sensor.py
        ├── services.yaml
        ├── strings.json
        ├── translations/
        └── brand/
```

复制完成后重启 Home Assistant，然后在“设置 → 设备与服务 → 添加集成”中搜索“荣浩燃气”。

## 添加集成时需要填写什么

在添加页面中，我需要填写荣浩燃气平台账号对应的接口参数：

- Bearer Token
- 用户档案 ID（`userfilesId`）
- 用户信息 ID（`userinfoId`）
- AES-128-ECB 密钥
- API 地址（一般保持默认值）

这些参数需要从你自己的荣浩燃气账号、原有 Node-RED 配置或抓包结果中取得。不同账号的参数不能混用。

## 实体和服务

集成会创建一台“荣浩燃气”设备，并提供账户余额、气量余额、燃气表读数、累计用气量、最近购气金额、最新用气量、最新用气金额、近 30 天用气数、近 12 个月用气数、最近一次用气时间、最近一次刷新时间以及燃气卡片数据等传感器。

需要立即更新时，可以在开发者工具中调用：

```yaml
service: ronghao_gas.refresh
```

也可以在服务数据中指定某一个配置项的 `entry_id`；不填写时会刷新所有荣浩燃气配置项。

## 安全说明

Bearer Token、用户 ID 和 AES 密钥都是个人账号数据。我没有把这些值写入仓库，也不建议把它们提交到 Git、截图、问题反馈或公开聊天中。添加集成时输入的凭据由 Home Assistant 保存，仓库只提供代码和配置流程。
